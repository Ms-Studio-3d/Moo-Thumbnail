# Moo-Thumbnail — Portable v1.0.0

برنامج Windows مستقل لاستخراج صور YouTube المصغّرة وحفظها بصيغة JPG.

## الاستخدام من دون تثبيت

1. حمّل `Moo-Thumbnail-1.0.0-Portable-x64.exe` من قسم Releases.
2. ضع الملف في مجلد يسمح بالكتابة، مثل مجلد خاص بك أو وحدة USB.
3. افتح EXE مباشرة. لا يحتاج Node.js أو npm أو صلاحيات مسؤول.
4. ألصق رابط فيديو واضغط «استخراج الصور».
5. اختر جودة متاحة ثم «حفظ الصورة» وحدد مكان الحفظ.
6. استخدم «نسخ الرابط» أو «فتح المجلد» عند الحاجة.

المتطلبات: Windows 10/11 بنواة x64 واتصال إنترنت لاستخراج الصور.
البرنامج لا يحمّل الفيديو ولا يرفع ملفاتك إلى خادم. يتصل بخادم صور YouTube فقط.
أسماء الجودات تعبّر عن ملفات YouTube؛ الأبعاد المعروضة مقاسة من الصورة نفسها.
عدم توفر جودة لا يعني وجود عطل في البرنامج. قد لا تكون كل الجودات موجودة للفيديو.

 SmartScreen مضمونة.
 Windows أو نجاح Actions قبل تشغيله في مستودعك.
Moo-Thumbnail أداة مستقلة غير تابعة لـ YouTube. استخدم الصور بما يتوافق مع حقوق أصحابها.
