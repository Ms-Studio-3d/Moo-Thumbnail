# Moo-Thumbnail

برنامج Windows خفيف لاستخراج الصور المصغّرة من فيديوهات YouTube، ومعاينتها وحفظها على الكمبيوتر بصيغة JPG.

## المميزات

- دعم روابط YouTube العادية والمختصرة وShorts وLive.
- فحص 6 خيارات لجودة الصورة.
- اختيار أفضل جودة متاحة تلقائيًا.
- عرض معاينة الصورة وأبعادها الفعلية.
- اختيار الجودة ومكان حفظ الصورة.
- نسخ رابط الصورة المباشر.
- فتح مجلد الصورة بعد الحفظ.
- واجهة عربية بألوان داكنة وفضية وبرتقالية.
- نسخة محمولة ونسخة للتثبيت.

## طريقة الاستخدام

1. افتح **Moo-Thumbnail**.
2. ألصق رابط فيديو YouTube.
3. اضغط **استخراج الصور**.
4. اختر الجودة المناسبة من الجودات المتاحة.
5. اضغط **حفظ الصورة** وحدد مكان الحفظ.

يمكنك أيضًا الضغط على **نسخ الرابط** لنسخ رابط الصورة، أو **فتح المجلد** للوصول إلى الصورة المحفوظة.

## متطلبات التشغيل

- Windows 10 أو Windows 11.
- ‎.NET Framework 4.8 أو أحدث.
- اتصال بالإنترنت لاستخراج الصور.

| النسخة | الاستخدام |
|---|---|
| **Portable** | تشغيل مباشر دون تثبيت، عند توفر متطلبات التشغيل. |
| **Setup** | تثبيت البرنامج وإضافة اختصارات لتشغيله. |

## ملاحظات

- البرنامج يحمّل الصورة المصغّرة فقط، ولا يحمّل الفيديو.
- الجودات المتاحة تختلف من فيديو لآخر حسب الصور التي يوفرها YouTube.
- البرنامج لا يحتاج تسجيل الدخول إلى حساب YouTube.
